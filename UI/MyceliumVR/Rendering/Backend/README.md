# Rendering Backend

Vulkan device, swapchain, and resource management.

## Key Files
- `VulkanRenderer.h/cpp`: High-level Vulkan backend orchestration.
- `VulkanBackend.h/cpp`: Swapchain management and frame state.
- `VulkanContext.h/cpp`: Instance, device, and memory allocator.
- `VulkanSwapchain.h/cpp`: Swapchain image and sync management.
- `VulkanResourceManager.h/cpp`: Buffer and image allocation helpers.
- `VulkanDebug.h/cpp`: Validation layers and debug markers.
- `VulkanProbe.h/cpp`: Hardware capability probing.
