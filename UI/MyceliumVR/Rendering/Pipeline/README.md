# Rendering Pipeline

Pipeline, material, and mesh building logic.

## Key Files
- `VulkanPipeline.h/cpp`: Graphics and compute pipeline creation.
- `VulkanPBRManager.h/cpp`: PBR material and descriptor management.
- `VulkanMeshBuilder.h/cpp`: GPU mesh data staging and formatting.
- `TextureLibrary.h/cpp`: Texture loading and caching.
